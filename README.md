One number, digits only, for make.fun's "How Many Tabs Do You Have Open?" bounty ($5 prize pool, top 10). The program writes `1` to `entry.txt`: exactly one browser tab is open — the make.fun competition page itself. The number is the winner of a 10-candidate head-to-head tournament judged with the competition's own judge brief: undefeated (12 wins, 0 losses). See TOURNAMENT.md for every pairing.
